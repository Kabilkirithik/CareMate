# CareMate Vfinal Frontend

Hospital dashboards (doctor, nurse, nutrition, utility, admin) built with TanStack Start + React.

## Quick start

```bash
npm install
cp .env.example .env   # optional
npm run dev
```

Ensure the backend is running at `http://localhost:8000` (see `../Vfinal/README.md`).

## Login

Use any synced staff email from `python ../Vfinal/print_accounts.py` with password `hospital123`.
